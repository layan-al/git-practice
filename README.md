# How Software Learns Personal Style

[Read the Stitch Fix article](https://newsroom.stitchfix.com/blog/how-we-understand-your-personal-style/)



I thought this article was interesting because it describes how software can learn something as personal as a person’s clothing preferences. Stitch Fix uses ratings to generate a “style map” that pairs shoppers with items they’ll love. What impressed me is that the system is able to find patterns across different people’s preferences and use those patterns to recommend something a shopper has never even rated.

It also made me think of how hard it can be to understand personal taste. Someone might like an outfit in a picture but not feel comfortable wearing it or want different styles for different occasions. I would like to hear how the system deals with those situations. This shows the importance of feedback in software development, that a good recommendation system needs to keep learning because people's preferences change.
